# Morális Iránytű / Moral Compass

**This branch is a stub. The project is on [`master`](../../tree/master).**

A touchscreen kiosk built for [Adaptér](https://adapterujbuda.hu/) and Szájensz Szeánsz: ten yes/no dilemmas about technology and society, each answered with an argument for the position you did not pick.
